# うろドロ

あいまいな記憶で描いて笑おう。オンラインで遊べるうろ覚えお絵描きゲーム。

## 概要

「うろドロ」は、お題を見本なしで、記憶だけを頼りに描くオンラインお絵描きゲームです。
友達同士でプライベート部屋に集まり、うろ覚えで描かれた絵を見せ合って楽しみます。

ゲームモードは2種類あります。

| モード | 内容 |
| --- | --- |
| うろドロ（通常モード） | 親がお題を出し、子が描き、親が1位を選ぶ |
| みんなでうろドロ | 全員がお題を出し、全員が他の人のお題をすべて描き、全員で順位を決める |

## 遊び方（開発中の最小版）

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開き、「部屋を作る」を押します。
表示された部屋URLを友達に共有すると、同じ部屋に入れます。

ステップ1〜5（両方のゲームモードと観戦機能）まで実装しています。

## 部屋と参加方法

### 部屋

- 部屋はプライベート部屋のみ（公開部屋はなし）
- 部屋を作成した人がホストになる
- 部屋URLの一部に完全ランダムな文字列を含め、推測で入室できないようにする
- ホストが部屋URLを共有し、URLを知っている人だけが入室できる

### 入室の流れ

1. 部屋を作る／部屋URLを開く
2. 名前とアイコンを設定する
3. 「参加者」か「観戦者」かを選ぶ
4. 部屋に入室する

### プレイヤー設定

- 名前：最大9文字。同じ部屋に同名のプレイヤーがいる場合は入室不可
- アイコン：用意されたデフォルメ動物から選択（重複可）

### 人数上限

| 区分 | 入室時の上限 |
| --- | --- |
| 参加者 | 9人 |
| 観戦者 | 10人（参加者とは別枠） |

- 上限に達している場合は「部屋が満員です」と表示する
- 入室後は参加者⇔観戦者を切り替えられる（ゲーム中に切り替えた場合は次のゲームから反映）
- 観戦者から参加者への切り替えは、参加者が9人いても可能（参加者が9人を超えることがある）

### 途中参加

- ゲーム中に「参加者」として入室した人は、参加者枠を1つ使い、次のゲームが始まるまで観戦モードで待機する
- ゲーム中に「観戦者」として入室した人は、そのまま観戦する
- 観戦モードでは閲覧のみ可能（描画・お題入力・いいねなどは不可）

## ホスト

### ホストだけができること

- ゲームモード・ゲーム設定の変更
- ゲームの開始
- 結果発表後の「次へ進む」
- ホスト権限の譲渡
- 部屋の強制終了

### ホスト権限の移り方

- 手動譲渡：ホストは他のプレイヤーを指定していつでも譲渡できる。反映はラウンドが切り替わるタイミング
- ホストが退出・切断した場合：入室順が次に早いプレイヤーへ自動で移る
  - ホストの操作でしか進まない場面（ロビー・結果発表）では即時に移る
  - 時間で自動的に進む工程（お題入力・お絵描き・1位選定など）では、次の工程に切り替わるタイミングで移る
- 元のホストが戻ってきても権限は自動では戻らない（戻す場合は現ホストが手動で譲渡する）

## ゲーム設定（開始前にホストが指定）

| 項目 | うろドロ（通常モード） | みんなでうろドロ |
| --- | --- | --- |
| お題入力時間 | 20〜50秒（初期値30秒） | 同左 |
| お絵描き時間 | 30〜200秒（初期値100秒） | 同左（1ラウンドごと） |
| 1周あたりの親の人数 | 1人〜参加人数（最大9人）、初期値は全員（9人を超える場合は9人） | なし |
| 周回数 | 1〜3周（初期値1周） | 1周固定 |

- 「全員」はその時点の参加人数として扱う
- 参加者が減って親の人数が参加人数を超えた場合は、参加人数に合わせて自動で下げる

## うろドロ（通常モード）

### 1ラウンドの流れ

1. 親をランダムに決める
2. 【お題入力ターン】親がお題を入力して決定する（設定時間）
3. 決定したお題が子に表示される
4. 【お絵描きターン】子がお題を記憶を頼りに描く（設定時間）
5. 【1位選定タイム】子の絵が並べられ、親が1位を1枚選ぶ
6. 【結果発表】1位と、それぞれの絵を描いた人を公開する
7. ホストが「次へ進む」を押すと次のラウンドへ

設定した周回数をすべて終えると、1ゲーム終了となります。

### 親の決め方

- 親はランダムに選ばれる
- その周でまだ親になっていないプレイヤーの中から選ばれる
- 抽選の時点で離席中のプレイヤーは候補から外す
- 周をまたいだ優先はなく、毎周完全にランダム（参加者が10人以上の場合、その周で親にならない人が出る）
- 途中退出などで候補がいなくなった場合は、今いるプレイヤー全員からランダムに1人選ぶ

### 1位選定タイム

| 子の人数 | 選定時間 |
| --- | --- |
| 9人以下 | 15秒 |
| 10人以上 | 30秒 |

- 選定中は誰がどの絵を描いたか表示しない（結果発表で公開）
- 絵が画面に収まらない場合はスクロールしてすべて見られる
- 時間内に選ばなかった場合は1位なしとし、親をちょっとからかうメッセージをランダムで表示する（例：「親は優柔不断です」）

### 結果発表中にできること

- 絵をタップして拡大表示
- 他の人の絵に「いいね」をつける
  - 1つの絵につき1人1回まで
  - いいねできる絵の枚数に制限なし
  - 自分の絵にはいいねできない
  - いいねは匿名。描いた人に「いいねされました」と通知が届く
  - いいねされた側は拒否できない

### 親が退出・切断した場合

| タイミング | 扱い |
| --- | --- |
| お題入力中 | 親を再抽選し、新しい親がお題入力からやり直す。抜けた親はその周で「親をやっていない」扱い |
| お絵描き中 | そのまま続行。1位選定タイムまでに戻れば通常どおり選定。戻れなければ1位選定をスキップし、1位なしで結果発表へ（「親が不在のため今回は1位なしです」と表示） |
| 1位選定中 | 選定時間内に戻って選べば有効。選ばれなければ1位なし |

## みんなでうろドロ

親と子の区別はなく、全員でお題を出し、全員で描き、全員で順位を決めるモードです。3人以上で開始できます。

### ゲームの流れ

1. 【お題入力ターン】全員がお題を1つずつ入力する
2. 【お絵描きパート】（参加人数−1ラウンド）
   - 各ラウンドで、全員にそれぞれ違うお題がランダムに配られ、同時に描く
   - 自分のお題と、すでに描いたお題は配られない
   - 全ラウンドが終わると、全員が自分以外のすべてのお題を1回ずつ描いたことになる
3. 【評価パート】全員が描き終わった後、お題ごとに順番に評価する
   - いいねフェーズ（30秒）：1人最大3人まで
   - ユニークフェーズ（30秒）：1人最大2人まで
   - 自分の絵にはいいね・ユニークをつけられない
   - 自分が出したお題では、描いた全員の絵を評価できる
4. 【結果発表】お題ごとに、いいね順位とユニーク順位を表示する（同数の場合は同率順位）

### プレイヤーが抜けた場合

- 2分以内に戻れば、そのまま続きから参加できる
- 戻れなかった場合は空席として扱い、以降のラウンドではその人に描く割り当てをしない
- 抜けた人がすでに描いた絵は残し、評価の対象にする
- 抜けた人が出したお題も残し、他の人は引き続き描く
- 抜けた人は評価パートには参加しない

## 成績の表示

- ランキング形式の総合成績は表示しない
- 名前の横に次の3つを常に表示する

| 成績 | 増えるモード |
| --- | --- |
| 1位の回数 | うろドロ（通常モード）のみ |
| いいねの数 | 両方のモード |
| ユニークの数 | みんなでうろドロのみ |

- 成績は部屋が終わるまで、ゲーム・モードをまたいで累積する

## 切断・退出と復帰

- 通信切断・自分での退出のどちらの場合も、2分間は席を保持する
- 2分以内に戻れば同じ部屋に復帰でき、成績も引き継がれる
- 2分経過すると席は解放される

## 部屋の終了

- 部屋に誰もいなくなってから2分間誰も戻らなければ終了（削除）する
- ホストは部屋を強制終了できる
- 部屋の終了とともに成績も消える

## プレイ時間の目安

| モード | 条件 | 目安 |
| --- | --- | --- |
| うろドロ | 9人・全員が親・1周・お絵描き100秒 | 約30分 |
| うろドロ | 同条件で3周 | 約1時間半 |
| みんなでうろドロ | 9人・お絵描き100秒 | 約30分（お絵描き約15分＋評価約9分＋その他） |

## 技術構成

| 役割 | 使用技術 |
| --- | --- |
| 言語 | JavaScript（慣れてきたらTypeScriptへの移行も検討） |
| フロントエンド | HTML / CSS / JavaScript（フレームワークなし） |
| 描画 | HTML Canvas（スマホのタッチ操作に対応） |
| リアルタイム通信 | Socket.IO |
| サーバー | Node.js |
| データ保存 | サーバーのメモリ上で管理（データベースなし） |
| 公開先 | Render など、常時接続（WebSocket）に対応したサービス |

- ゲームの進行（タイマー・抽選・権限・席の保持など）はすべてサーバー側で管理する
- 入室時にプレイヤーごとのランダムなIDを発行して端末に保存し、復帰時の本人確認に使う

## 検討事項・実装メモ

- お題の文字数上限（案：20文字程度）
- 設定の刻み幅（仮：お題入力時間は5秒刻み、お絵描き時間は10秒刻み）
- うろドロ（通常モード）の最少人数（親1人＋子1人の2人から？）※現在は2人から開始できるようにしている
- みんなでうろドロで、評価中に描いた人・お題を出した人を伏せるか ※現在は評価中はどちらも伏せ、結果発表で公開している
- みんなでうろドロのいいね・ユニークは、各フェーズ中なら付け外しできる。成績への加算と「付きました」の通知はフェーズの終わりにまとめて行う
- 部屋URLのランダム文字列は英数字10文字以上を目安にする
- 「親は優柔不断です」系のメッセージは10種類程度用意し、親の名前を差し込めるようにする
- ホストの名前に👑などの印をつけ、権限の移動は全員に通知する
- 離席中のプレイヤーは名前とアイコンを半透明にして「離席中」と表示する
- ホスト譲渡と部屋の強制終了には確認ダイアログを挟む
